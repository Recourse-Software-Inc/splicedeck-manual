Welcome

Thank you for choosing SpliceDeck for your DaVinci Resolve editing suite.

If you edit, grade or deliver in Resolve every day, you already know the rhythm: find the moment, mark it, cut it, check it, render it. SpliceDeck puts that rhythm under your fingers. Every key and dial on your Stream Deck is connected to Resolve through its official scripting interface, so the deck always shows what is really happening in your project: the timecode under the playhead, the colour of the clip you are parked on, the markers ahead of you, the page you are working on and how far along your render is.

Because SpliceDeck talks to Resolve directly instead of pretending to be a keyboard, it works with any keyboard layout and any custom shortcut set, and it never presses the wrong key when Resolve is in a different window. When something stops it working, the keys tell you exactly what is wrong and how to fix it.

SpliceDeck runs on macOS and Windows in the Elgato Stream Deck app, and on Linux in OpenDeck. Every key works on every Stream Deck model, and the dials and touch strip of Stream Deck + turn into jog wheels, marker maps, colour pickers and render controls.

This manual contains everything you need to install SpliceDeck, connect it to Resolve and get the most out of all 53 actions. Start with Getting Started to be editing within a few minutes, then dip into the chapters for the parts of Resolve you use most.

We hope SpliceDeck becomes the part of your suite you stop noticing because it simply keeps up with you. Enjoy your edit!

Getting Started

At first glance a deck full of live keys can look like a lot to learn. In practice SpliceDeck is quick to set up: you install one plugin, switch on one setting in Resolve, and every key starts showing live information straight away.

This section shows you how to install SpliceDeck, connect it to DaVinci Resolve Studio, put your first keys on the deck and make your first edits with them.

Turning On External Scripting in Resolve

SpliceDeck controls Resolve through the scripting interface that Blackmagic Design built into Resolve Studio. For safety it is switched off when Resolve is installed, so the first time you use SpliceDeck you need to allow local scripting.

  1. In DaVinci Resolve Studio, open DaVinci Resolve > Preferences on macOS, or File > Preferences on Windows and Linux.

  2. Select the System tab, then General.

  3. Set External scripting using to Local, then click Save.

  4. Quit and reopen Resolve so the change takes effect.

External scripting using Local 3

Choose Local. The Network option also works, but it lets other computers on your network script your Resolve, which SpliceDeck does not need.

NoteIf a Resolve dialog is open, for example Preferences, a save prompt or a render settings window, Resolve pauses all scripting until you close it. SpliceDeck's keys show Offline or stop updating while the dialog is open and recover by themselves as soon as you close it.

Checking the Connection

Put a Resolve Status key on your deck. It is the quickest way to see whether SpliceDeck can talk to Resolve, and it explains in plain words what to do when it can't.

Connected. A green bar and dot. The key shows your project, timeline, page or Resolve version, whichever you choose in its settings.

Offline. Resolve isn't running. SpliceDeck reconnects by itself when Resolve starts.

Script off. Resolve is running but refuses the connection. Switch on external scripting as described on the previous page.

Press the Resolve Status key to retry the connection straight away. Hold it for a moment to see diagnostics: how quickly Resolve is answering while connected, or the exact reason SpliceDeck can't connect while offline. Help at the end of this manual lists every state the keys can show.

Checking Python

SpliceDeck's connection to Resolve runs in a small Python program, because Resolve's scripting interface is built for Python. You don't need to know any Python, but it has to be installed.

  • macOS. Install Python 3 from python.org or with Homebrew (brew install python).
  • Windows. Install Python 3 from python.org and keep py launcher selected in the installer. SpliceDeck also looks in the usual install folders.
  • Linux. Use your distribution's python3 package.

TipIf a key says No Python, open the settings of any SpliceDeck key, expand SpliceDeck settings at the bottom, and type the full path to your Python in Python interpreter. Leave it empty to go back to automatic detection.

Getting Started8

Turning On Turbo Jog

Resolve's scripting interface only lets other programs move the playhead about twice a second. To make jogging as smooth as a hardware editing panel, SpliceDeck can also use Resolve's own frame-step commands, which are not limited. This is called Turbo Jog, and it needs one permission on macOS.

  1. On macOS, open System Settings > Privacy & Security > Accessibility.

  2. Switch on Elgato Stream Deck. If it isn't listed, click + and add it from your Applications folder.

  3. Quit and reopen the Stream Deck app.

Turbo Jog only sends frame steps while Resolve is the frontmost app, which is always the case while you work, because the Stream Deck never takes focus away from Resolve. The frame steps travel on their own stream, separate from everything else SpliceDeck does, so nothing waits on them. When you stop turning, SpliceDeck reads the playhead back once and, if anything doesn't line up, lands it on the exact frame through the scripting interface. On Windows no permission is needed. On Linux, Turbo Jog works in X11 sessions.

NoteWithout the permission, jogging still works and always lands on the right frame. Resolve's viewer just updates about twice a second while you spin, instead of on every frame.

Getting Started9

Your First Edit

With Resolve Studio open on the Edit page and a timeline loaded, try this. On a Stream Deck + with the SpliceDeck profile, the deck is already showing the Edit page:

  1. Turn the Playhead Jog dial. The playhead moves one frame per click, faster the quicker you spin. The touch strip above shows the timecode and a small map of the timeline.

  2. Tap the jog's touch strip to switch to Scroll mode, then turn the dial: each click now moves 1% of the timeline. Tap again to go back to Jog. Pressing the dial in also steps through the modes: Jog by frames, Jog by seconds, Scroll, and back to frames.

  3. Hold Shift on your keyboard and turn the jog dial. The strip shows ZOOM and the dial zooms the timeline in and out. Press it to zoom to fit. Let go of Shift to jog again.

  4. Press Add Marker. A blue marker appears at the playhead in Resolve, and the Marker Dial's map shows it immediately.

  5. Press Mark In, jog forward, then press Mark Out. The In/Out Dial's strip shows the range and its duration.

  6. Press Previous Marker to jump back to the marker you added, then hold Add Marker: Resolve opens its Markers panel so you can name the marker.

  7. Press Split to cut the clip at the playhead. Hold it instead to ripple delete the clip under the playhead. Use Edit > Undo in Resolve to put it back.

  8. Press Save Project. The key confirms the save and shows how long ago you last saved.

ImportantSpliceDeck works on your real project. Keys like Save Project, Render Preset and Duplicate Timeline do exactly what they say. While you are learning, practise on a copy of your project or a spare timeline.

Understanding SpliceDeck

You can use SpliceDeck without knowing anything about how it works inside. A few minutes with this chapter will still pay off: once you know where the information on each key comes from, you can read the deck at a glance and you will always know why a key is behaving the way it is.

This chapter explains how SpliceDeck talks to DaVinci Resolve, how to read a key, which Resolve pages each action works on, and how the SpliceDeck profile used throughout this manual is laid out.

How SpliceDeck Works

SpliceDeck has three parts that work together. You install them all at once with the plugin, and they start and stop by themselves.

SpliceDeck plugin
Runs inside the Stream Deck app. It draws every key and touch strip and reacts to your presses, turns and touches.

SpliceDeck bridge
A small Python program that holds the connection to Resolve and does the work you ask for.

DaVinci Resolve Studio
Answers through its official scripting interface, the one Blackmagic Design documents for developers.

A key press travels from the plugin to the bridge, which asks Resolve to do it. Resolve's answer and every change in your project travel back the same way.

The bridge is the only part that talks to Resolve. It keeps one connection open for as long as Resolve is running, finds Resolve again by itself when you restart it, and tells the keys in plain words when something is in the way.

Understanding SpliceDeck11

Live state

Between your presses, the bridge keeps asking Resolve what has changed: the playhead, the current page, the clip under the playhead, markers, In and Out points, tracks, timelines and render progress. Only the changes are sent to the plugin, and only the keys that show that information are redrawn.

The bridge asks more often while you are working and less often when nothing happens. Right after a change it checks again within 40 ms, when everything is quiet it slows down to a few times a second, and after a minute of no activity to once a second. The page and the playhead have their own fast lane, so a page you open with the mouse lights up on the deck almost instantly. When no SpliceDeck key is visible on your Stream Deck, the bridge checks only every two seconds.

TipOn a laptop running on battery, open SpliceDeck settings at the bottom of any key's settings and set Polling to Balanced or Battery saver. The keys update a little less often and Resolve does less work. Responsive is the default.

Turbo Jog, a separate lane for the jog dial

Resolve's scripting interface accepts a new playhead position only about twice a second. That is fine for jumping to a marker, but far too slow for a jog wheel. So the Playhead Jog dial has a second, independent connection called Turbo Jog.

Turbo Jog is a separate small process. It does not use the scripting connection at all. Each click of the dial becomes one of Resolve's own Previous Frame and Next Frame commands, sent straight to Resolve, the same way a hardware editing panel does it. Nothing waits for the bridge, for polling or for an answer, so the viewer follows the dial frame by frame.

The touch strip shows where the playhead is going while you turn. About a fifth of a second after you stop, SpliceDeck checks the real position once through the scripting connection and lands the playhead on exactly the frame the strip showed. If Turbo Jog can't be used, for example because Resolve is not the frontmost app or macOS has not given the Stream Deck app Accessibility permission, the dial carries on through the scripting connection automatically. Navigating the Timeline explains Turbo Jog in more detail, and Getting Started shows how to give the permission.

Understanding SpliceDeck12

Why Keys Are Not Keystroke Macros

Many Stream Deck plugins for video editing work by pretending to be a keyboard: a key press sends a shortcut and hopes that the right window is in front and that the shortcut has not been changed. SpliceDeck works differently. Almost every action asks Resolve directly, through the scripting interface, to do one exact thing, and reads the result back.

  • Any keyboard layout and shortcut set. Your custom keyboard mapping in Resolve never changes what a SpliceDeck key does.
  • No wrong window. A key never types into a browser or a mail window by mistake.
  • Keys show the truth. Because SpliceDeck reads Resolve's state, a key can show the marker it will jump to, the colour of the clip you are parked on or how far a render has got.
  • Clear refusals. When Resolve can't do something, the key says why, for example No clip here or Wrong page, instead of silently doing nothing.

A few things are not available in Resolve's scripting interface at all. For these, SpliceDeck uses Resolve's own commands, and only while Resolve is the frontmost app:

  • Turbo Jog sends Resolve's Previous Frame and Next Frame commands (the Left and Right arrow keys).
  • Timeline zoom on the jog dial, while you hold Shift, uses the View > Zoom menu on macOS and Resolve's default zoom shortcuts on Windows.
  • Split on the Split / Ripple Delete key uses Resolve's Timeline > Split Clips menu item on macOS and its default shortcut on Windows.

NoteEven these commands are checked. Turbo Jog confirms every spin by reading the playhead back, and if the frames don't line up, for example because you have remapped the arrow keys in Resolve, SpliceDeck switches Turbo Jog off for that dial and keeps working through the scripting connection.

Understanding SpliceDeck14

Status colours

Red, amber and green are never used as group colours. They are kept for status, so they always mean the same thing: green is connected or done, amber is a warning or something to check, and red is an error, a refusal or a render that is running and can be stopped.

Lit keys

Many keys light up when what they stand for is true right now: a Switch Page key while its page is open, a Clip Color key when the clip under the playhead already has that colour, a Mark In key when the playhead sits exactly on the In point. Lit keys follow Resolve, so they also change when you do the same thing with the mouse.

Confirmations and errors

When a key has done its job, it briefly shows a green confirmation, such as Done, In/Out cleared or the new mode of a dial. When Resolve refuses, the key shows a short red message for just over a second, for example No clip here, Track locked or Resolve refused, and the Stream Deck app adds its own alert triangle. Then the key returns to its normal face.

If Resolve is busy with something long, such as saving a large project or loading a page, keys that show live values add a small Saving… or Loading page… label instead of showing a frozen value as if it were current.

When a key can't work

A key that can't work right now draws its symbol struck through with a status-coloured line and one or two words that explain why. Presses are ignored, so nothing happens by accident, and the key goes back to normal by itself as soon as the problem is solved.

Understanding SpliceDeck18

The deck follows Resolve

Whenever Resolve changes page, whether you turn the Page Dial, click a page tab or press a keyboard shortcut, the Stream Deck + jumps to the matching page of the SpliceDeck profile. You never have to switch pages on the deck yourself.

  • Only confirmed changes. The deck follows the page Resolve has actually opened. While you are still turning the Page Dial it stays where it is, so the dial under your finger is never replaced mid-spin.
  • Only the SpliceDeck profile. SpliceDeck switches only to its own profile and never to one of yours.
  • Stream Deck + only. Other models have no dials and do not get the bundled profile. Build your own pages for them, as described in Devices, Profiles and Settings.

Turbo Jog

Resolve's scripting interface only accepts a new playhead position about twice a second. To jog as smoothly as a hardware editing panel, Playhead Jog uses Turbo Jog whenever it can. Turbo Jog is a separate process from SpliceDeck's connection to Resolve: each click becomes one of Resolve's own Previous Frame and Next Frame commands, sent straight to Resolve. Nothing waits for an answer or for the next update, so Resolve's viewer follows the dial frame by frame.

While you spin, SpliceDeck also pauses its background checks of Resolve, so Resolve can spend all its time drawing frames. About a fifth of a second after you stop turning, SpliceDeck reads the real playhead position once and, if needed, lands the playhead on exactly the frame the strip shows.

Turbo Jog works when all of these are true:

  • Resolve is the frontmost app. This is normally the case while you work, because the Stream Deck never takes the focus away from Resolve.
  • On macOS, the Stream Deck app has Accessibility permission. Getting Started shows how to switch it on. Windows needs no permission. On Linux, Turbo Jog works in X11 sessions.
  • Resolve is on the Edit, Cut, Color or Fairlight page.
  • The dial is in JOG mode. SCROLL mode, very large steps and jumps to edits and markers always use the scripting connection.

When any of these is not true, the dial simply carries on through the scripting connection. It still lands on the right frame every time, but Resolve's viewer updates only about twice a second while you spin.

NoteTurbo Jog uses Resolve's default Previous Frame and Next Frame keys, the Left and Right arrows. If you have mapped those commands to other keys, SpliceDeck notices that the playhead does not end up where it should, and after a few spins it switches Turbo Jog off for that dial and uses the scripting connection instead.

Markers

Markers are the notes you leave in a timeline: a shot to fix, a line to check, a beat to cut on. SpliceDeck lets you drop, find, recolour and remove them without reaching for the mouse.

The Markers group has six actions. Five are keys: Add Marker, Next Marker, Previous Marker, Delete Marker and Marker Color. The sixth, the Marker Dial, puts all of them on one dial of a Stream Deck +, with a map of every marker on the touch strip.

From left: Add Marker, Previous Marker, Next Marker, Delete Marker and Marker Color. Every key shows live information about the markers around the playhead.

How the Marker Keys Work

  • They are always up to date. SpliceDeck reads the markers of the current timeline all the time. A marker you add or delete with the mouse shows on the keys straight away.
  • They know which marker you are on. When the playhead is on a marker, or anywhere inside a marker that has a duration, the keys treat it as the marker "under the playhead".
  • They are frame accurate. Add Marker and the Marker Dial note the frame at the moment you press, so a marker lands where you meant even while Resolve plays.
  • They work on the timeline or on a clip. Each marker action has a setting called Add to or Markers of: leave it on Timeline, or choose Clip under playhead (beta) to use the markers of that clip instead.
  • They use Resolve's 16 marker colours: Blue, Cyan, Green, Yellow, Red, Pink, Purple, Fuchsia, Rose, Lavender, Sky, Mint, Lemon, Sand, Cocoa and Cream. Colour menus in the settings have a row of swatches underneath, so you can pick by colour as well as by name.

NoteResolve only has a playhead on the pages with a timeline, so markers can be added on the Cut, Edit, Color, Fairlight and Deliver pages.

Using Multi-Actions

A Stream Deck multi-action runs several actions, one after the other, from a single key. SpliceDeck key actions can be part of a multi-action, with a few things to keep in mind.

  • Dial actions can't be added. Playhead Jog, Marker Dial and the other dial actions are not available in multi-actions.
  • Each step is a single press. Hold gestures, such as holding Add Marker to open Resolve's Markers panel, don't apply inside a multi-action.
  • Use fixed actions instead of toggles. Set On press on Track On/Off to Turn on or Turn off, and on Track Lock to Lock or Unlock, so the multi-action always ends in the same state. Press again to go back on Switch Timeline is ignored inside a multi-action.
  • Give slow steps time. Opening the Fusion or Color page on a large project can take a moment. Add a Delay step after it if a later step depends on it.

For zoom, Split and the Markers panel, SpliceDeck presses the items in Resolve's menus for you rather than typing shortcuts, so it works with any keyboard layout and any custom shortcuts in Resolve. SpliceDeck finds the Split Clips and Modify Marker items by their English names, so these two need Resolve's user interface set to English.

TipIf Elgato Stream Deck is already switched on in Accessibility but Turbo Jog or Split still doesn't work, macOS may be holding on to an old permission. Select it in the list, click - to remove it, add it again with +, then quit and reopen the Stream Deck app.

Windows

Windows needs no permission. SpliceDeck sends Resolve's default shortcuts, and only while Resolve is the foreground window: Ctrl+= to zoom in, Ctrl+- to zoom out, Shift+Z to zoom to fit and Ctrl+\ to split. If you have changed these shortcuts in Resolve's keyboard customisation, or use a keyboard layout where these keys are in different places, zoom and Split may not work. The Markers panel can't be opened on Windows, so set Hold the key on Add Marker to Delete the marker under the playhead or Nothing.

Performance

Resolve doesn't tell other programs when something changes, so SpliceDeck asks. Many times a second it checks the page, the playhead, your markers, render progress and the other things your keys show, and it redraws only the keys whose information has changed. Each check takes a few milliseconds and doesn't slow Resolve down.

SpliceDeck checks more often while things are changing and less often when nothing is happening. The page you are on and the playhead are checked on a fast lane of their own, so a page you click with the mouse, or playback you start in Resolve, reaches the deck almost at once. The Polling setting sets how often SpliceDeck checks:

PollingWhile changingIdleIdle over a minutePage and playhead
Responsive40 ms300 ms1 s50 ms
Balanced66 ms500 ms1.5 s80 ms
Battery saver100 ms1 s3 s150 ms

Responsive is the default. Choose Battery saver on a laptop running on battery. Presses on the deck always light up straight away, whichever profile you choose. While a render is running, progress is checked at most four times a second, and when no SpliceDeck key is visible, SpliceDeck checks only every 2 seconds.

Why Turbo Jog Exists

Resolve's scripting interface accepts a new playhead position only about every 500 milliseconds. A jog wheel driven only through scripting would update Resolve's viewer twice a second, and every other key would wait behind it. Resolve's own frame-step commands have no such limit, so Turbo Jog sends those instead and checks the result through scripting once you stop turning. While you spin the dial, SpliceDeck also pauses its checks on Resolve, so Resolve can spend all its time drawing frames. The checks resume within half a second of the last turn.

The SpliceDeck Harness

The SpliceDeck harness is a Stream Deck that runs in your web browser. It starts the real SpliceDeck plugin exactly the way the Stream Deck app does, and draws every key, dial and touch strip live, at the resolution of the real hardware. You use it with the mouse.

The harness is a tool for building and testing SpliceDeck. You don't need it to use SpliceDeck with your Stream Deck. It is useful for trying out a layout, seeing what a key does without touching your project, or checking a change to SpliceDeck's source code.

By default the harness doesn't connect to your Resolve at all. It uses a mock Resolve: a simulated copy of Resolve with a project, a timeline, clips, markers and a render queue, which you can change from the harness itself. Nothing you do in mock mode can affect a real project.

What You Need

  • The SpliceDeck source folder.
  • Node.js 20 or later, with npm.
  • Python 3.8 or later, as for the plugin. The mock Resolve runs in Python too.

Starting the Harness

  1. Open a terminal in the SpliceDeck folder and install the dependencies with npm install. You only need to do this once.

  2. Build the plugin with npm run build. The harness runs the built plugin, so build again after changing the source.

  3. Start the harness with npm run harness. The terminal prints the address of the harness, normally http://127.0.0.1:5199.

  4. Open that address in your browser. To stop the harness, press Ctrl+C in the terminal.

TipUse the 127.0.0.1 address rather than localhost, which can point at a different program. If port 5199 is busy, the harness moves to the next free port and prints the new address. To choose a port yourself, run node harness/server.mjs --port 5300.

Connection Problems

Keys Go Offline While a Resolve Dialog Is Open

While a dialog is open in Resolve, for example Preferences, a save prompt or the render settings, Resolve pauses all scripting. SpliceDeck's keys show Offline or stop updating until you close the dialog, and then recover by themselves. A press made while the dialog was open is dropped with Resolve was busy rather than carried out later.

Script Off or Can't Connect

Resolve is running but refuses SpliceDeck's connection. There are two possible reasons, and Resolve doesn't say which one it is.

  1. Check that you have DaVinci Resolve Studio. Open DaVinci Resolve > About DaVinci Resolve. The free edition of Resolve doesn't allow external scripting, so SpliceDeck can't work with it.

  2. Check that External scripting using is set to Local in Preferences > System > General, as described in Getting Started.

  3. Quit and reopen Resolve after changing the setting.

No Python

SpliceDeck's connection to Resolve needs 64-bit Python 3.8 or later. The Stream Deck app starts plugins with a very short list of places to look for programs, so a Python that works in your terminal may still be missed.

  1. Install Python 3 as described in Checking Python in Getting Started.

  2. If the keys still say No Python, find the full path to your Python. In a terminal, type which python3 on macOS or Linux, or py -3 -c "import sys; print(sys.executable)" on Windows.

  3. Click any SpliceDeck key in the Stream Deck app, expand SpliceDeck settings and paste the path into Python interpreter.

Help98

Resolve Not Found

The keys show No API when SpliceDeck can't find Resolve's scripting files. It looks in the places Resolve installs them on each system, including /opt/resolve and /home/resolve on Linux. If Resolve is installed somewhere else, enter the folder that contains Resolve's scripting modules in Resolve scripting API folder, and the path to fusionscript in fusionscript library. Hold the Resolve Status key to see which paths SpliceDeck tried.

Reconnecting

SpliceDeck reconnects on its own when Resolve starts, restarts or quits, and when your computer wakes from sleep. It tries again quickly at first and then every 3 seconds. On macOS and Windows, it reconnects the moment Resolve starts. To reconnect straight away at any time, press the Resolve Status key or any key that shows a status word.

Turbo Jog, Zoom and Split

Jogging Updates Only Twice a Second

When Turbo Jog isn't available, the Playhead Jog dial moves the playhead through the scripting interface, which Resolve limits to about two updates a second. The playhead still lands on the right frame. Check the following:

  • Accessibility on macOS. Elgato Stream Deck must be switched on in System Settings > Privacy & Security > Accessibility. See Turning On Turbo Jog in Getting Started.
  • Resolve in front. Turbo Jog only works while Resolve is the frontmost app. Click in Resolve's window once.
  • The page. Turbo Jog works on the Cut, Edit, Color and Fairlight pages, and in Jog mode. In Scroll mode, and on other pages, the dial uses scripting.
  • Frame-step shortcuts. Turbo Jog uses the Left and Right Arrow keys, Resolve's Previous Frame and Next Frame commands. If you have assigned these commands to other keys in Resolve, Turbo Jog can't be used.
  • Linux. Turbo Jog needs an X11 session. It isn't available under Wayland.

Turbo Jog checks every move. If Resolve doesn't follow the frame steps three times in a row, the dial stops using Turbo Jog to keep the playhead accurate. Switch to another Stream Deck page and back to try again.

A Marker Isn't Added

  • Wrong page. Markers can't be placed on the Media or Fusion page, because Resolve doesn't report the playhead there. Switch to the Cut, Edit, Color, Fairlight or Deliver page.
